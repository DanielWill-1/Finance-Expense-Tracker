# Security policy

GhostLedger keeps data in local SQLite files and binds to loopback by default. Do not expose an unauthenticated instance to a network. Remote mode does not add authentication.

## Reporting a vulnerability

Please report suspected security issues privately. If the Git hosting service offers private vulnerability reporting for this repository, use that channel. If it is unavailable, contact the repository maintainer through a private channel listed on the project profile. Do not post exploit details, credentials, database files, or real financial records in a public issue.

Include the affected version or commit, operating system and Node version, a concise reproduction using synthetic data, and the impact you observed. Remove API keys, personal identifiers, statement contents, and other sensitive values from logs and screenshots.

Please limit testing to a copy of the project and data that you own. Do not attempt to access another person's device or database.
